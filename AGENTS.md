# Repository instructions

- Treat this as an evidence-first chat-system practice, not a production messenger.
- Keep durable acceptance, database synchronization, server socket write, client claim, screen display, and human reading separate.
- Preserve the immutable closed-book contract; record later corrections in the research log or an ADR.
- Do not log bearer/ticket values, user/device IDs, client message IDs, message text, or cursor contents.
- Run `npm run check:ci` against PostgreSQL 17.6 before publishing implementation claims.
- Do not add real user data, production credentials, copied third-party prose, or unlicensed images.
